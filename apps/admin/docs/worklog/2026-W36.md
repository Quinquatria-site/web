SEED 가 가장 강한 영역인 폼 한 화면으로 먼저 재보기로 했다. 되돌리기는 커밋 하나면 된다.

**차후 작업 계획**

- **Table 결정** — 목록 화면을 만드는 순간 부딪힌다. SEED 프리미티브 조립 / TanStack Table / 자체 `src/ui/Table` 중 선택
- 테마 토큰을 덮어써서 당근 브랜드 색을 바꿀 수 있는지 조사

**user 전달사항**

  (참고로 `apps/user/next-env.d.ts` 도 같은 목록에 잡히는데 이건 Next 생성 파일이고 이전부터 그랬다.)

**주의사항**

  `types` 에 `"node"` 를 넣어야 했다. 브라우저 앱에 node 타입이 들어간 상태다.

`ui-primitive` 스킬은 직전에 자체 `src/ui/` + `tokens.css` 전제로 썼는데, SEED 도입과 정면으로

직접 만드는 순서다. 자체 `tokens.css` 는 만들지 않고 SEED 의 CSS 변수를 쓴다.

셋 다 걸리지 않았다. 대신 예상 못 한 `process` 미정의가 걸렸다.
